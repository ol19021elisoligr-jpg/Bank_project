# Bank Project — анализ клиентской базы банка

Учебный проект по анализу данных клиентов банка.  
В ноутбуке `Bank_project.ipynb` выполнены загрузка, очистка, исследовательский анализ данных и статистическая проверка гипотез.

# Цель проекта

- Изучить портрет клиентов банка.
- Сравнить группы клиентов по кредитной дисциплине: `GOOD`, `MIDDLE`, `BAD`.
- Проверить, различаются ли группы по количеству и суммам переводов.
- Сформулировать выводы для сегментации клиентов.

## Данные

Используется файл `dataset_segment_bank.csv`.

Основные признаки:

- `Идентификатор`
- `Дата рождения`
- `Дисциплина клиентов без просрочки по кредиту` — целевой признак: `GOOD`, `MIDDLE`, `BAD`
- `Количество переводов`
- `Тип переводов`
- `География переводов`
- `География телефона`
- `Сумма перевода`
- `Канал, через который пришел клиент`
- `Оператор связи`
- `Пол`
- `Возраст` — создан в ходе анализа

## Инструменты

- Python 3
- pandas, numpy
- matplotlib, seaborn
- scipy.stats

## Этапы работы

1. Загрузка данных и первичный просмотр.
2. Очистка данных:
   - удаление дубликатов;
   - обработка пропусков;
   - исправление аномалий;
   - преобразование типов;
   - расчёт возраста клиента.
3. Исследовательский анализ данных:
   - распределение целевого признака;
   - возраст, пол, канал привлечения;
   - география переводов и телефона;
   - операторы связи;
   - типы переводов;
   - количество и суммы переводов по группам.
4. Статистическая проверка гипотез:
   - проверка нормальности распределений (Колмогоров-Смирнов);
   - сравнение групп с помощью U-критерия Манна-Уитни.
5. Формулировка выводов.

## Основные результаты

- Распределение целевого признака:
  - `GOOD` — 54.15%;
  - `MIDDLE` — 27.29%;
  - `BAD` — 18.56%.
- Клиенты `GOOD`: чаще женщины, возраст в среднем 48–65 лет, приходят через офис, пользуются МегаФон/МТС, переводят около 9 раз, медианная сумма ~200 000 руб.
- Клиенты `MIDDLE`: самая высокая активность по количеству переводов (около 10–11), медианная сумма ~190 000 руб.
- Клиенты `BAD`: чаще мужчины, приходят через партнёра, переводят реже (около 6 раз) и на меньшие суммы (~140 000 руб.).
- Женщины совершают переводы чаще, мужчины — на более крупные суммы.
- Основной канал привлечения — офис, второй — партнёр. Через партнёра больше клиентов с дисциплиной `BAD`.
- Основной регион переводов — Москва и Московская область (77).  
  Топ операторов: МегаФон, МТС, Вымпел-Коммуникации.

## Статистические выводы

- Распределения количества и суммы переводов не являются нормальными.
- По U-критерию Манна-Уитни различия между группами `GOOD`, `MIDDLE`, `BAD` статистически значимы.
- `MIDDLE` переводит чаще, но `GOOD` — на большие суммы.
- `BAD` — наименее активная группа с меньшими суммами.

## Как запустить

1. Склонируйте репозиторий.
2. Установите зависимости:  
   `pip install pandas numpy matplotlib seaborn scipy`
3. Положите файл `dataset_segment_bank.csv` в папку с ноутбуком.
4. Откройте `Bank_project.ipynb` в Jupyter Notebook, JupyterLab или VS Code.
5. Выполните ячейки по порядку.
